Q3. Pourquoi épingler une version (@v4) plutôt que @main ?

- @v4 permet d'utiliser une version précise et plus stable. En revanche, @main peut changer à tout moment, ce qui peut modifier le comportement de l'action ou introduire des risques de sécurité.

Q4. Le badge Verified Creator garantit-il qu'une action est sûre ?

- Non. Ce badge indique que GitHub a vérifié le créateur comme organisation partenaire, mais il ne garantit pas que le code de l'action est totalement sécurisé.

Q5. Quelles vérifications effectuer avant d'utiliser une action inconnue en production ?

- Examiner le code source et vérifier la réputation du créateur.

- Vérifier les versions, les dépendances et les éventuelles alertes de sécurité, puis privilégier une version épinglée par SHA de commit.
